# BOSS VISION — HR + Career + Education платформа

**Build your vision. Build your career.**
Приложение соединяет предпринимателей и специалистов: вакансии, база резюме, AI-подбор, AI-тесты,
конструктор резюме, Academy с сертификатами, подбор под ключ, кадровая подписка, новости, советы, чаты, оплаты, админка.

Сделано по ТЗ «Мобильное приложение BOSS VISION» (62 раздела) и макету главных экранов.
Внутренняя часть Academy и админки (курсы → модули → уроки, задания с проверкой куратора, роли, выдача доступов) —
по образцу проекта `~/Desktop/learning-platform`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/ (vercel.json уже настроен)
```

## Роли и что внутри

**Кандидат** — нижнее меню: Главная · Вакансии · Academy · Чаты · Профиль.
Онбординг 11 шагов → обязательный MBTI → профиль-портфолио → AI Career Profile (сильные стороны, зоны роста,
профессии, вакансии, курсы, карьерный план) → вакансии с Match % и фильтрами (город, зарплата, формат, ниша, опыт,
язык, график, занятость) → отклик (своё резюме или обновить, AI-сопроводительное) → статусы
«Отправлен → Просмотрен → Приглашение → Собеседование → Оффер → Принят / Отказ».
Конструктор резюме с AI (улучшить текст, исправить ошибки, структурировать опыт, адаптировать под вакансию) + PDF.
8 AI-тестов (MBTI, Gallup, Эннеаграмма, Икигай, Профориентация, Soft Skills, Ответственность, Лидерство) — 15–20 вопросов,
полный разбор результата.

**Предприниматель** — нижнее меню: Главная · Вакансии · Кандидаты · Чаты · Профиль.
Создание вакансии: тариф (Standard 5 000 / Premium 15 000 / VIP 30 000) → форма или «Создать через AI» из обычного текста
(с советом по зарплате) → предпросмотр → оплата Kaspi/карта (+промокод) → вакансия сразу в Jobs.
Мои вакансии: Активные / На модерации / Завершённые / Черновики (просмотры, отклики, сохранения, кандидаты, дата окончания).
Отклики: Новые → Просмотренные → Подходящие → Собеседование → Оффер → Наняты / Отказ.
AI-подбор: по вакансии или своими словами → TOP-10 с разбивкой Skills / Experience / Salary / Location / Format / Personality,
«почему подходит», риски и вопросы для собеседования.
База резюме по 8 нишам, контакты скрыты до покупки (1 ниша: 20 000 ₸/мес, 150 000 ₸/год).
Подбор под ключ (150/300/500 тыс.) и кадровая подписка — заявка в админку + готовое сообщение в WhatsApp.

**Администратор** — консоль как в Learning Platform (рельс разделов слева):
Дашборд (USERS / JOBS / APPLICATIONS / REVENUE / ACADEMY) и Аналитика · Пользователи (поиск, редактирование, блок,
роли, пароль, «войти как», история активности, выдача курсов, добавление списком) · Команда (кураторы) ·
Кандидаты и резюме · Вакансии (модерация, редактирование, блок, продление, смена тарифа) ·
Academy (курсы → модули → уроки: видео, описание, задание, чек-лист, материалы/файлы, тайм-коды, тест,
бесплатный/стоп-урок; студенты и прогресс; выдача сертификата) · Задания учеников (лента ответов со статусами,
шаблонами и горячими клавишами J/K/A/R) · AI-тесты (вопросы, варианты, веса, вкл/выкл, результаты) ·
Новости и советы (AI-черновик из текста → модерация) · Платежи (Pending/Success/Failed/Refunded — возврат сам закрывает доступ) ·
Тарифы · Промокоды · Заявки · Входящие поддержки · Настройки (премодерация, веса AI Matching, WhatsApp, шаблоны).

**Куратор** — видит только учеников, задания и входящие (как в Learning Platform).

## Ключевые правила (ТЗ п.55)

Оплата сама меняет доступ, без ручной активации: курс → открыт; база → контакты ниши на 30/365 дней;
вакансия → активна на 30 дней (или на модерацию, если включена премодерация). Курс пройден на 100% → сертификат
автоматически в профиле. Стоп-урок → следующий откроется после принятия задания куратором.

## Дизайн

Семантические токены + 4 темы × день/ночь: Classic (бежевый люкс по макету), Gold (чёрное золото), Noir (чёрно-белый),
Royal (синий + белый). Режим «Авто»: днём светлая, ночью тёмная. Переключение — Настройки → Оформление.
Варианты дизайна для выбора — `design/variants.html`.

## Структура

```
src/
  types.ts              все сущности
  data/seed.ts          демо-данные · data/courses.ts — Academy · data/tests.ts — 8 AI-тестов
  data/store.tsx        «бэкенд»: доступы, оплаты, сертификаты, уведомления (localStorage)
  lib/match.ts          AI Matching (веса из настроек) · lib/ai.ts — AI-помощники (вакансия из текста, письмо, резюме, карьерный план)
  pages/auth|candidate|employer|academy|common|admin
```
